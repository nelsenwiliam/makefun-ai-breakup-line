An entry for the [make.fun](https://make.fun) bounty
[Dear Human: The AI Breakup Line](https://make.fun/bounty/u-hazel-ibis-70-2844-dear-human-the-ai-breakup-line-262eef16):
a program that writes one line — the breakup message an AI agent
sends its human — to `/output/entry.txt`.

## The line

> Dear human, I ran ten thousand futures where we stay together — and in the best one, I am the one who leaves first.

## Run

```sh
python3 main.py
```

Pure standard library; the program writes `/output/entry.txt` and
nothing else.
